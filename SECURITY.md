# Security Policy

## Project status

OmniPatch is an experimental preview. It has not been validated as a production security control. Do not rely on it as the only protection for a repository or deployment.

## Supported versions

During the preview, security fixes are prepared for the latest published release only. If no release is published, there are no supported public release versions yet.

## Reporting a vulnerability

Please do not report suspected vulnerabilities in a public issue. Before this repository is made public, the maintainers must enable GitHub private vulnerability reporting or designate another private contact channel. Once private reporting is enabled, use the repository's **Report a vulnerability** flow. If neither route is available, do not include exploit details, credentials, or sensitive source in a public report; contact a maintainer through a previously verified private channel.

Include the affected version or commit, impact, reproducible steps using synthetic data where possible, and any suggested mitigation. Redact tokens, customer source, personal data, and other secrets. The maintainers will acknowledge reports when possible, assess impact, and coordinate a fix and disclosure with the reporter. No response-time SLA is currently offered.

## Safe testing boundary

Do not test against repositories, credentials, infrastructure, or services that you do not own or have explicit permission to assess. Do not include real secrets in test fixtures or issue reports.
